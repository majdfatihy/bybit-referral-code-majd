* 🎥 **مكتبة شروحات فيديو تفاعلية:** قائمة مندمجة بأبرز الشروحات المصورة (بالعربية) لتوثيق الحساب، تأمين السحب، استخدام البوتات، وحل مشاكل الإيداع.
* 🎨 **خلفية تفاعلية متطورة (Canvas Star/Net Animation):** تأثيرات بصرية حركية في الخلفية تتفاعل بسلاسة مع حركة مؤشر الماوس واللمس.
